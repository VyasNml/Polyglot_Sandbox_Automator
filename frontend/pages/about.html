Motivation

Why This Project Exists

The Polyglot Sandbox Automator was built as an exploration into one of the harder problems in backend engineering: how do you safely execute arbitrary, untrusted code at scale without compromising host system integrity?

Platforms like Leetcode, HackerRank, and Replit solve this problem in production. PSA is an attempt to understand and replicate the core mechanisms at a smaller scale — with a focus on correctness, security, and observability over raw performance.

The project integrates real production tools — Docker, FastAPI, Linux cgroups — in a way that mirrors how they'd be used in an actual backend engineering environment. Every design decision was made with real-world constraints in mind.

This is not a toy project. It is a structured engineering exercise with concrete architecture decisions, documented trade-offs, and measurable outcomes.

Engineering First

Every component is designed with production-like constraints — no shortcuts, no placeholder implementations. Resource limits, timeouts, and cleanup are real mechanisms.

Open Documentation

All architectural decisions, trade-offs, and learnings are documented openly. The goal is to be a learning resource for others exploring the same problem domain.

Academic Context

This project was developed as part of an academic curriculum focused on backend systems, DevOps, and cloud-native engineering. The goal was to bridge theory and practice through implementation.
